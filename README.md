# agent-rules

LLM·코딩 에이전트에게 주는 규칙 모음. 프로젝트마다 다시 쓰지 않으려고 한곳에 모은다.

각 프로젝트는 여기서 필요한 규칙을 골라 자기 `rules/` 아래로 내려 쓴다.

## 구조

```
writing/            글쓰기·문체 규칙
  references/       규칙의 근거가 되는 배경 자료 (규칙 아님)
coding/             코딩 에이전트 규칙 (예정)
```

## 넣는 것 / 안 넣는 것

**넣는다**
- 프로젝트와 무관하게 재사용되는 규칙
- 가상 예시로만 설명되는 규칙
- 규칙의 근거가 되는 배경 자료 (`references/` 아래)

**안 넣는다**
- 특정 저장소의 결정 사항, 날짜가 붙은 판단 기록
- 개인 정보, 실제 회사·프로젝트 이름
- 한 번 쓰고 버릴 프롬프트

애매하면 **"다른 프로젝트에서 이 파일을 그대로 가져다 쓸 수 있는가"** 로 가른다.
못 쓰면 그 프로젝트의 `rules/` 에 둔다.

## 파생본

프로젝트로 내려간 규칙은 **그 프로젝트가 정본**이다. 프로젝트별 결정이 덧붙기 때문에
여기로 되돌려 합치지 않는다. 한쪽만 고쳐도 되도록 방향을 한 방향으로 고정한다.

| 규칙 | 파생본 | 그 문서를 쓸 때의 정본 |
|---|---|---|
| `writing/이력서_에이전트_국문_문체_규칙.md` | RESUME `rules/문체.md` · `rules/문체_문서별.md` · `rules/문체_검사.md` | RESUME 쪽 |
