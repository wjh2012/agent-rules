# 문서 구조 — 마크다운

> 문장 수준 규칙은 `문체.md` 에 있다. 이 문서는 **문단·표·불릿·제목의 배치**만 다룬다.
> 문서 종류를 가리지 않는다 — README·가이드·스펙·이슈 본문 모두 해당한다.

README·가이드·스펙 등 모든 문서에 적용한다. 목표는 **읽는 사람이 훑어서 원하는 정보를 빨리
찾게 하는 것**이다.

> 코드 가독성 규칙이 "명시적으로 쓴다"이듯, 문서도 같다. 산문 한 덩어리에 사실을 욱여넣지 말고
> **정보를 구조로 드러낸다.**

## 핵심 원칙

- **한 문단 = 한 주제.** 서로 다른 사실을 한 문단에 이어 붙이지 않는다.
- **구조로 보여준다.** 병렬 항목은 불릿, "항목 × 속성"은 표, 절차는 번호 목록으로 쓴다.
  산문에 녹이지 않는다.
- **훑을 수 있게 한다.** 제목·표·불릿으로 찾을 수 있어야 한다. 긴 산문은 훑어지지 않는다.

> 마크다운에서 소스의 한 줄바꿈은 렌더링에서 공백이 된다. 여기서 말하는 "줄바꿈"은 소스를
> 칼럼에서 접는 것이 아니라 **문단·불릿·표로 정보 단위를 끊는 것**이다.

## 1. 거대 문단을 만들지 않는다

여러 사실을 마침표나 가운뎃점(`·`)으로 이어 한 문단에 몰아넣지 않는다.
**한 문단 4~5문장**을 넘으면 주제별로 나누거나 불릿·표로 분해한다.

서로 다른 항목(메서드·필드·상태값·단계)을 나열할 때는 산문이 아니라 **불릿 또는 표**로 쪼갠다.

```text
❌ 한 문단에 진입점·흐름·코드값이 전부 섞임
XxxService(접수 N행 + 작업 시작; 진입점 3종 — 직접 업로드 a(N건), 경로 목록 b(N건),
압축파일 c) → 워커 변환 → 완료 리스너(커밋 후 수신 → 디스패처 위임 …) → 조회 → 다운로드.
코드값은 상수 사용. 상태는 다단계로 기록한다 — 접수(10)→변환완료(40)→업로드완료(55)→…
```

```text
✅ 흐름은 짧은 문단, 나열은 표로 분해
처리 흐름: 접수 → 워커 변환 → 완료 리스너 → 조회 → 다운로드.

**진입점**

| 진입점 | 입력 |
|---|---|
| `convert` | 파일 직접 업로드 (N건) |
| `convertByPath` | 인입 루트 상대경로 목록 (N건) |
| `convertByZipPath` | 압축파일 1개 |

**상태 코드**

| 코드 | 의미 |
|---|---|
| `10` | 접수 |
| `40` | 변환완료 |
```

## 2. 중첩 괄호로 부연하지 않는다

괄호 안에 또 괄호를 넣지 않는다(깊이 1까지). 부연이 길어지면 **별도 문장이나 불릿**으로 뺀다.

```text
❌ 접속 정보(5요소(host 필수, port/user/password)+분류값(gateway/id))를 받는 carrier
✅ 접속 정보를 담는 carrier. 접속 5요소(host 필수, port·user·password)와
   분류값(gateway·id)으로 구성된다.
```

## 3. 표

"항목마다 같은 속성을 갖는" 구조는 산문 대신 표로 적는다.

- 헤더는 명사 한두 단어로 짧게.
- **셀에 한 문단을 통째로 넣지 않는다.** 길어지면 표 아래 별도 절로 빼고 셀에는 요약만 남긴다.
- 코드·식별자는 백틱으로 감싼다.

## 4. 불릿

절차·선택지·병렬 규칙은 불릿이나 번호 목록으로 적는다.

- **한 불릿 = 한 항목.** 불릿 하나가 여러 문장을 넘기면 하위 불릿으로 쪼갠다.
- 핵심 용어를 굵게 앞세워 훑어지게 한다.
- 순서가 의미 있으면 번호 목록, 없으면 불릿.

## 5. 제목으로 쪼갠다

한 절 아래 산문이 길어지면 하위 제목을 만들어 훑을 지점을 둔다.
**제목만 봐도 문서의 뼈대가 보여야 한다.**

## 6. 표기

- **코드·경로·식별자·설정키·상태값은 백틱**으로 감싼다.
- **문서 간 링크는 상대경로 + 설명 텍스트**로 쓴다. 벌거벗은 URL 을 두지 않는다.
- 코드 블록에 언어 태그를 붙인다.

## 7. 소스 줄바꿈 (권장)

렌더링에는 영향이 없지만, 긴 문단의 소스를 문장 경계에서 접으면 **diff 와 리뷰 가독성**이
좋아진다. 강제하지 않는다. 표 행은 접지 않고 한 줄로 둔다.

## 점검 체크리스트

- [ ] 한 문단이 4~5문장을 넘지 않는가? 넘으면 쪼갰는가?
- [ ] 같은 속성을 갖는 나열을 산문이 아니라 표·불릿으로 적었는가?
- [ ] 괄호 깊이가 1을 넘는 곳이 없는가?
- [ ] 표 셀에 한 문단을 통째로 넣지 않았는가?
- [ ] 코드·경로·식별자를 백틱으로 감쌌는가?
- [ ] 제목만 훑어도 문서 구조가 파악되는가?
